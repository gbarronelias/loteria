# Lotería

Generador y simulador de una lotería 4x4.

1. Abre `index.html` en el navegador.
2. Selecciona **Generar Tableros** para crear diez tableros aleatorios.
3. Usa **Descargar imagen** en cada tablero para guardarlo como PNG.
4. Usa **Descargar todos (ZIP)** para descargar las imágenes PNG de todos los tableros en un solo archivo ZIP.
5. Selecciona **Simular partida** para barajar y cantar las cartas hasta que una tabla se complete.
6. El resultado muestra el ganador, el número de turnos y las cartas cantadas.
